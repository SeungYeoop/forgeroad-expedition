## 1. 화면 구성 (가장 중요)

1. **땅 띠가 화면 아래 3분의 1 지점.** 캐릭터가 걷는 땅선이 화면 높이 약 65~75%에 가로로 길게 놓인다. 그 위가 풍경, 아래는 단면과 물이다.
2. **땅 단면 + 물 전경 (모든 야외 장면의 서명).**
   - 땅선 바로 위는 풀 가장자리다. 들쭉날쭉한 풀잎이 땅선 위로 2~6px 삐죽 솟고, 군데군데 덤불·꽃·버섯이 있다.
   - 땅선 아래 10~25px은 흙 단면이다. 진한 흙에 돌멩이, 뼈, 해골, 물고기 뼈, 뿌리가 박혀 있다.
   - 그 아래 화면 끝까지는 **검고 잔잔한 물(늪·해자)**이다. 위 풍경이 어둡고 흐리게 거꾸로 비치고, 연잎, 갈대·부들(노란 꽃대), 수초가 앞에 솟는다. 물 위에 반딧불이나 불씨 빛이 반사된다.
3. **캐릭터는 작다.** 사람 키가 화면 높이의 약 1/8이다. 환경이 화면을 압도한다.
4. **넓은 파노라마 + 층층 시차.** 앞에서 뒤로: 물·갈대(가장 빠름) → 땅 단면 → 땅 위 소품·건물 → 가까운 큰 나무 → 숲 띠 → 먼 산·언덕(성·폐허 실루엣) → 구름 → 하늘·해·달.

## 2. 층별 그리는 법

- **하늘:** 위에서 아래로 부드러운 그라데이션이다. 낮은 하늘색에서 밝은 지평선으로, 밤은 짙은 청록에서 옅은 청록으로 간다. 별은 작은 흰 점을 듬성듬성 찍는다.
- **해·달:** 크고 강한 빛무리(블룸)를 준다. 해 둘레로 노란 링과 넓은 흰 번짐이 퍼지고, 앞 나무·천막 가장자리가 역광으로 하얗게 탄다(ref07). 달은 구름 사이 초승달에 빛이 번진다(ref03).
- **구름:** 크고 뭉툭한 덩어리다. 위가 밝고 아래가 어두운 2~3단 평면 음영이고, 가장자리는 계단식 픽셀이다. 지글거리는 디더링은 쓰지 않는다.
- **먼 산·언덕:** 넓고 부드러운 실루엣에 낮은 대비, 하늘색으로 많이 묻힌다. 면은 큰 덩어리 2~3단 음영이다. 꼭대기에 성·폐허·탑 실루엣을 작게 올린다(ref01·03).
- **숲 띠:** 침엽수 실루엣이 빽빽하게 이어진 띠다. 한 색조 안에서 명도로만 구분하고, 먼 띠일수록 옅고 푸르다.
- **가까운 큰 나무:** 화면 높이를 넘는 거대한 활엽수 덩어리다. 잎은 큰 둥근 뭉치마다 밝은 윗면, 중간, 어두운 아랫면을 굵게 칠한다. 마른 고목은 가지가 갈라지는 실루엣으로 대비를 준다(ref02·07).
- **안개:** 땅 위와 숲 띠 앞에 낮고 넓게 깔린 반투명 띠다(ref03·05). 먼 층을 흐리게 묶어 깊이를 만든다.

## 3. 색과 빛

- **장면마다 한 가지 분위기 색.** 낮은 하늘색과 녹색에 따뜻한 햇빛, 밤 숲은 청록, 달밤은 세피아·회갈색 단색, 실내는 호박색·주황 불빛.
- **채도는 낮고 흙빛 위주.** 강한 색은 불·깃발·천막 장식(빨강)·보물(금색)에만 쓴다.
- **명도로 앞뒤를 나눈다.** 먼 곳은 밝고 흐리게, 가까운 곳은 진하고 대비 높게. 대기 원근이 아주 강하다.
- **광원이 장면을 만든다.** 횃불, 모닥불, 랜턴 기둥, 촛불 샹들리에, 불타는 건물 둘레에 넓은 주황 빛무리(더하기 혼합)를 깔고, 불씨 입자가 위로 날린다. 실내는 창이나 문틈에서 비스듬한 빛줄기가 들어온다(ref04·06).
- **밤 장면:** 반딧불(노란 점)과 불씨가 화면을 수놓는다.

## 4. 픽셀 화법

- 깨끗한 색 덩어리 위주다. **베이어 디더링이나 잡음 결을 넓게 깔지 않는다.** 지금 우리 bgart는 디더링이 많으니 줄일 것.
- 외곽선은 선택적이다. 가까운 소품·건물만 진한 같은 계열 색으로 테를 두르고, 먼 층은 외곽선 없이 실루엣으로 둔다.
- 하이라이트는 손으로 찍은 듯 빛 방향(대개 위·해 쪽) 가장자리에만 1px 밝은 테를 넣는다.
- 질감은 나무판 결(세로 줄 + 마디), 돌 블록(큰 돌 + 줄눈), 이엉·널지붕(굵은 가로 결)을 반복 패턴 대신 크기를 바꿔 그린다.

## 5. 건축·소품 (중세·북유럽)

- **집:** 돌 기단 위 세로 나무판벽, 두꺼운 널·이엉 지붕(처마가 깊고 그늘 진함), 작은 나무 창과 덧창, 굴뚝. 장식은 적고 묵직하다(ref01).
- **성·실내:** 큰 돌기둥, 벽 횃불과 쇠 받침, 어두운 큰 문과 깃발, 넓은 돌계단(ref04). 연회장은 조각된 나무 들보, 2층 난간, 아치 격자 창, 촛불 샹들리에, 둥근 방패와 술 장식 깃발, 통 선반(ref06).
- **야영·전장:** 물결 모양 붉은 띠 장식 천막, 깃발 장대, 보물 상자, 나무 상자, 통, 무기 거치대, 말뚝 울타리, 나무 망루, 투석기, 모닥불, T자 랜턴 기둥(ref02·05·07).
- **자연:** 거대한 활엽수, 마른 고목, 침엽수 띠, 바위 첨봉(ref07), 덤불, 갈대·부들, 연잎, 들꽃.

## 6. 우리 엔진에 옮길 때 (작업 체크리스트)

1. 야외 구역과 거점은 **땅선 아래 흙 단면 띠 + 물 반사 전경 띠**를 기본으로 깐다. 전경 물은 가장 빠른 시차, 갈대·연잎은 그 위.
2. 배경 층 5~6장을 쓴다: 하늘(그라데이션+해/달 블룸) → 먼 산(언덕 위 성·폐허) → 침엽수 띠(옅게) → 안개 띠 → 가까운 큰 나무 → 땅 위 소품.
3. 각 층은 **평면 2~3단 음영 덩어리**로 칠한다. 디더링은 최소로 하고, 대기 원근은 강하게 한다.
4. 광원(횃불·모닥불·랜턴·창)마다 넓은 더하기 빛무리와 불씨 입자를 넣고, 밤이면 반딧불을 넣는다.
5. 캐릭터 대비 환경 크기를 키운다. 나무·건물이 화면 높이의 절반을 넘기게 한다.
6. 장면마다 분위기 색 하나를 정하고 그 안에서 명도로 층을 나눈다.
